# dotfiles

Personal dotfiles for CachyOS (Arch) + GNOME, managed with [chezmoi](https://chezmoi.io).
Secrets are encrypted with [age](https://github.com/FiloSottile/age) and are safe to commit.

## What's inside

| Path in repo | Applied to | Notes |
| --- | --- | --- |
| `dot_config/fish`, `ghostty`, `tmux`, `micro`, `btop`, `git`, `mise`, `herdr` | `~/.config/*` | Shell, terminal, editor and tool configs |
| `dot_config/opencode` | `~/.config/opencode` | `opencode.jsonc` is age-encrypted (contains API keys) |
| `dot_config/easyeffects`, `private_dot_local/private_share/easyeffects` | `~/.config`, `~/.local/share` | EasyEffects settings and Dolby presets/IRs |
| `dot_config/autostart` | `~/.config/autostart` | Bitwarden, EasyEffects |
| `dot_config/gh/private_config.yml` | `~/.config/gh/config.yml` | `hosts.yml` (token) is not tracked |
| `dot_config/environment.d`, `mimeapps.list`, `user-dirs.dirs` | `~/.config/*` | Session env vars, default apps, XDG dirs |
| `dot_claude/settings.json` | `~/.claude/settings.json` | Claude Code settings |
| `dot_agents/skills`, `.skill-lock.json` | `~/.agents/` | Agent skills (installed via the skills CLI) |
| `private_dot_ssh` | `~/.ssh` | Public key + age-encrypted `config` |
| `private_dot_local/bin` | `~/.local/bin` | Small helper scripts |
| `packages/` | not applied directly | `pacman.txt` / `aur.txt` package lists |
| `dconf/` | not applied directly | GNOME settings dump (`gnome.ini`) |

`README.md`, `packages/` and `dconf/` are listed in `.chezmoiignore`, so they live in the repo but are not copied to `$HOME`.

## How encryption works

`.chezmoi.toml.tmpl` is the template for `~/.config/chezmoi/chezmoi.toml`. It only tells chezmoi to use age,
where the identity (private key) file is, and the **public** recipient. No secret is in it.

The private key is `~/.config/chezmoi/key.txt`. It is **not** in this repo. Keep a copy in Bitwarden.
Without it the `encrypted_*.age` files cannot be decrypted.

## Scripts (`.chezmoiscripts/`)

- `run_onchange_before_10-install-packages`: installs anything from `packages/pacman.txt` (pacman) and `packages/aur.txt` (yay) that is missing. Re-runs when either list changes.
- `run_onchange_after_20-load-dconf`: runs `dconf load /org/gnome/` from `dconf/gnome.ini`. Re-runs when the file changes.

## New machine

1. Install chezmoi: `sudo pacman -S chezmoi`
2. Restore the age key from Bitwarden to `~/.config/chezmoi/key.txt` and `chmod 600` it.
3. `chezmoi init --apply <repo-url>`

This installs packages, applies all files and loads the GNOME settings.

## Daily use

- Edit: `chezmoi edit ~/.config/fish/config.fish` (or edit in place, then `chezmoi re-add`)
- Check drift: `chezmoi status` / `chezmoi diff`
- Track a new file: `chezmoi add <file>`
- Track a secret file: `chezmoi add --encrypt <file>`
- Refresh package lists: `packages/dump.sh`
- Refresh GNOME settings: `dconf/dump.sh`

## Intentionally not tracked

- `~/.config/herdr/plugins.json`: machine-specific absolute paths, regenerated by herdr.
- `~/.config/gh/hosts.yml`: auth token.
- codex / gemini configs: tokens and volatile per-project state.
- `~/.agents/commands`: generated by the Superset app.
- `~/.zshrc`, `~/.bashrc`, `~/.bash_profile`: CachyOS defaults.
